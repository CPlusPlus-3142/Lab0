# Lab 0 – Environment Check

The purpose of this lab is to verify that your development environment is working correctly before we begin programming assignments.

## Instructions

1. Clone this repository to your computer.
2. Open the project in VS Code or Visual Studio.
3. Modify `hello_world.cpp` so that it prints:

```
Hello, world!
```

4. Compile and run the program.
5. Commit your changes with a descriptive commit message.
6. Push your changes to GitHub.

## Submission

Your assignment is complete when your changes have been pushed to your GitHub repository.
